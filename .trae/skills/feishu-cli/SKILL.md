# Feishu CLI (Lark CLI) 技能

这是一个允许 AI Agent 直接操控飞书真实数据的技能。它通过底层调用 `@larksuite/cli` (即 `lark-cli` 命令) 来完成所有复杂的飞书操作，无需手动查阅或调用飞书的 Open API。

## 使用场景

- 用户要求“帮我获取第三轮的会议记录”
- 用户要求“在飞书新建一个需求文档”
- 用户希望直接把看板卡片同步到飞书多维表格中
- 任何需要 AI Agent 操控飞书、读取或写入飞书真实数据的场景

## 使用方式

1. **环境准备**：
   确保项目中已安装 `@larksuite/cli`。可以通过 `npx lark-cli` 来执行操作。

2. **执行命令**：
   直接使用终端工具执行对应的 `lark-cli` 命令，你可以通过 `npx lark-cli --help` 来查看支持的指令范围（涵盖文档、日历、消息、表格等模块）。

3. **自然语言调用优势**：
   你可以直接通过 `npx lark-cli api` 等方式，组合用户的自然语言意图来操作系统。

## 注意事项
- 初次使用时可能需要进行飞书授权登录（`npx lark-cli auth`）。
- 始终以用户的真实意图为准，返回的数据可以结合项目本地的渲染逻辑进行展示。
